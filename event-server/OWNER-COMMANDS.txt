CURRENT BEHAVIOR
Mintop MX is the default, with four laps. Races restart manually.
The shared erode is whatever riders successfully vote for or the owner
sets. Erode is preserved across races and game process restarts.

A successful track vote selects that track for the next race restart.
Loading it begins its allowance. Its third subsequent restart returns
to Mintop, even when the races were restarted before anyone finished.
The initial load and first two subsequent restarts stay on the voted track.
Voting for another track renews the allowance for that selection.

PUBLIC IN-GAME COMMANDS
server,listtracks                 Show the current track numbers.
server,callvote settrack #         Vote to select a track number.
server,callvote erode #            Vote to set erode (0 through 100).
server,vote yes                    Vote yes on the current proposal.
server,vote no                     Vote no on the current proposal.

Replace # with the actual track number or desired erode amount.
The bordered welcome lists these commands and the live track catalog.
It appears once when a rider loads in, including after a race restart.
Existing lap-time, invalid-lap, holeshot, winner and record notices remain.
