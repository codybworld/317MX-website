TONIGHT'S PLAN
Decker Training Facility is pinned for qualifying. Ordinary restarts
stay on Decker, and track changes/votes cannot move it while pinned.
The normal qualifying format is the existing three-lap Decker setting.
Your current erode is retained; it is not reset by this event update.

Public signups close at the scheduled start time, even if the controller
is paused or the UID grab is disarmed. Finished events never accept
public signups. The completed Mintop Test Fun Race, its entries and
both saved moto results are available in Finished Events.

At 11:30 PM EST the game captures connected Player/Spectator UIDs.
The fastest 40 signed-up riders present with a clean flying lap on
Decker qualify. Opening laps from the gate do not count: complete at
least two laps for your first qualifying time. Times persist across
restarts and are collected during this event's qualifying window.

The controller runs a one-lap lineup check/warmup, then Moto 1 and Moto 2
(15 minutes + 1 lap each). After checkered there is up to a 60-second
finish window, followed by a 30-second intermission. If all starters
finish, results can finalize after five seconds. No-finisher timeouts
pause the event after seven minutes in warmup or 25 minutes in a moto.

Lowest sum of moto positions wins; better Moto 2 finish breaks ties.
3-1 beats 1-3. 3-3 beats 1-5. DNS scores 41. Started DNFs receive their
classified finishing position with a DNF label. Cut-adjusted timing is
used. Results are provisional until both motos are saved; exact remaining
ties share an overall position. Owner corrections remain possible.

MANUAL OPERATION
Use MANUAL PROGRESSION to prevent the next session starting automatically.
Use DISARM SCHEDULED START if you do not want the 11:30 UID grab to run
automatically. Public entries still close at 11:30. GRAB UIDS NOW captures
eligible riders currently present. Then LINEUP CHECK / WARMUP, START MOTO
1 and START MOTO 2 let you run each stage yourself. NEXT SESSION starts
the queued next stage. PAUSE PROGRESSION stops event progression; it
does not freeze bikes. During qualifying, PAUSE disarms the UID grab:
use ARM SCHEDULED START to re-arm before 11:30.

The dashboard can register or correct an entry as owner, add/remove a UID
from the selected lineup after UID grab, correct saved moto positions,
change erode, send a white bordered announcement and restart the current
race. The public signup deadline does not remove your owner override.
Roster is capped at 40. Adding an already-selected rider restores their
player mode for the next restart. Unselected newcomers remain spectators
while event control is active. Event starts/reruns and result corrections
have a confirmation dialog so a stray click cannot trigger them.

warmup. If a race is restarted early, the director pauses without awarding
that aborted moto. Use RERUN SESSION. A game process restart pauses an
