IN-GAME SERVER CONTROL

SERVER COMMAND DECK

Open the chat/console in MX Simulator and use these commands to browse the rotation or start a vote. Replace # with the track number or erode amount you want.

01

SEE TRACK NUMBERS

Show the numbered track list before choosing the next layout.

server,listtracks
02

VOTE FOR A TRACK

Start a vote using the number shown by the track-list command.

server,callvote settrack #
03

VOTE FOR ERODE

Start a vote for the erode value you want the server to use.

server,callvote erode #

Votes must pass in the server. The # symbol is a placeholder—type a number in its place.
